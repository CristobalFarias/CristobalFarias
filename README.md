## 👨‍💻 Qué hago

Desarrollo plataformas completas: backend, web, app móvil, escritorio e IA, todo conectado.

- **Plataformas web** — backends y APIs REST con Django, paneles de administración y aplicaciones en React.
- **Pagos en línea** — integración con pasarelas de pago chilenas e internacionales.
- **Apps móviles** — clientes en React Native (Expo) con TypeScript sobre APIs REST.
- **Asistentes con IA** — integración de modelos de lenguaje en productos reales.
- **Aplicaciones de escritorio** — con PyQt6, C# y Electron.
- **Infraestructura** — Docker, AWS, Terraform y despliegue continuo con GitHub Actions.

## 🎯 Hacia dónde voy

Quiero consolidarme como **desarrollador full stack**, enfocado en:

- **Plataformas SaaS escalables** con Django y React, bien probadas y fáciles de mantener.

- **Integrar inteligencia artificial** en productos reales: asistentes que actúan por el usuario y análisis de datos.
